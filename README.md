# Сайт АО «Омтранснефтепродукт»

Одностраничный сайт: речные перевозки светлых нефтепродуктов и сухих грузов.
Vite + GSAP (ScrollTrigger) + Lenis, без фреймворков.

```
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # готовая сборка в dist/
```

- `index.html` — разметка и тексты.
- `src/data.js` — флот (характеристики 20 проектов), контакты, реквизиты, должности. Источник — omtnp.ru.
- `src/main.js` — рендер данных и анимации; `src/styles.css` — стили.
- `src/brand/logo.svg` — логотип из `OMTNP.svg` (Yandex.Disk/омтранс), разбит на диск, вышку и судно для анимации.
- `public/media/` — ролик для первого экрана (все кадры ключевые, чтобы перемотка прокруткой шла плавно) и фото.
- `design/source/` — исходный ролик Magnific и первый кадр.

Заявка с сайта открывает письмо на omtnp@omtnp.ru в почтовой программе посетителя (сервера нет).
