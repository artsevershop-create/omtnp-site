# Сайт АО «Омтранснефтепродукт»

Многостраничный сайт: речные перевозки светлых нефтепродуктов и сухих грузов.
Vite (MPA) + GSAP/ScrollTrigger + Lenis + Three.js (только страница «География»), без фреймворков.

```
npm install
npm run dev      # генерирует страницы судов и запускает сервер
npm run build    # готовая сборка в dist/
```

## Страницы
`/` главная · `/uslugi/` перевозки · `/flot/` флот · `/flot/<slug>/` 20 страниц судов (генерирует `scripts/gen-vessels.mjs`, в git не хранятся) · `/geografiya/` 3D-карта · `/kompaniya/` · `/rabota/` · `/kontakty/`

## Устройство
- `partials/` — общие блоки; в HTML подключаются комментарием `<!-- @имя -->` (плагин в `vite.config.js`).
- `src/data.js` — флот, контакты, реквизиты (источник — omtnp.ru).
- `src/lib/core.js` — шторка между страницами, курсор, магнитные кнопки, появление текста, заявка.
- `src/lib/vessel-svg.js` — силуэты и чертежи судов по реальным размерам.
- `src/scenes/` — сцена рейса и 3D-география; `src/pages/` — код отдельных страниц.
- `public/media/` — ролик первого экрана (все кадры ключевые для плавной перемотки) и фото.

Заявка открывает письмо на omtnp@omtnp.ru в почтовой программе посетителя (сервера нет).
